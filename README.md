# codesaga

The story of a git repository: how active it is, who built it, where knowledge sits and whether it is still in the team, and how much of the work AI agents and bots do. It reads the local git history only, so it works offline, for any host and any branch. Humans get a self-contained HTML dashboard, agents and scripts get versioned JSON.

Work in progress: the workspace and the CLI skeleton exist, the analysis does not yet.
